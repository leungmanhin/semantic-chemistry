# `tests/` — the Mortal Semantic Chemistry suite

Each `*_test.metta` file loads the engine modules it exercises (+ the Exp-1 data where needed), wires a scenario, and runs its own `!(test …)` assertions — so it **both demonstrates** a slice of the stack **and verifies** it. The *generic* logic lives in `../petta/`; the test file is thin (import + scenario + asserts). A failing `!(test)` prints `is X, should Y. ❌` and halts that file (`../../PeTTa/src/metta.pl`). The reference for correctness is **Ben's `docs/` PDFs**.

## Run

```sh
sh tests/run_suite.sh              # from the repo root (or anywhere in the repo)
```

Runs every `tests/*.metta` from the repo root (imports are repo-root-relative), tallies ✅/❌ per file, and exits non-zero on any failure. **Suite: 224 tests green.** One file at a time:

```sh
sh ../PeTTa/run.sh tests/grounder_test.metta < /dev/null 2>&1 | grep should
```

## The tests

- ✅ **solve pipeline** (`grounder_test.metta`, 8; logic `petta/grounder` + the engine) — the Exp-1 pipeline on the **§10.1 sem-graph IR** (V3): the parser's surface molecules carry discourse cues only; the **derivation genome** (`rules.metta`: `R_so`/`R_result` normalize cues → `ReasonFor`, `R_trans` chains **derived** edges) fires fuel-gated on the organisms' purses (3 firings — O_base's R_so/R_result @ sm, O_chain's R_trans @ sm + tr); then the parser's *why*-skeleton grounds against the derived graph **2 ways** (proximate + root cause, cited by provenance-bearing ids `(norm E)`/`(trans E1 E2)`; the mechanism chain is carried by the root cite's trans-id provenance, never by the query's shape).
- ✅ **evaluator** (`evaluator_test.metta`, 23; logic `petta/evaluator`) — **achievement-typed minting** on the solve pipeline: Match binary per grounding (every solution mints); achievements detected structurally (`skeleton-match` always; `transitive-explanation` when the cited derivation is a chain, depth ≥ 2 off the provenance ids) and converted to typed fuel by `(clamp-mint …)` facts — the **TYPED clamp-switch**: sm income equal under both clamps (4 = 4), **tr income 0 (`CL_shallow`) vs 2 (`CL_deep`)**, so only the deep clamp replenishes what `R_trans` spends; **provenance-based crediting** routes each grounding to the organism whose rule derived its cited edge (proximate → `R_result` → `O_base`; root → `R_trans` → `O_chain`).
- ✅ **epoch loop** (`epoch_test.metta`, 15; logic `petta/epoch`) — the metabolic-closure cycle (a reduced TECAN epoch, Alg 5.1): the LITERAL typed-starvation, 1-vs-2-answer death. Each cycle re-derives (fuel-gated) → mint+credit → **`decay`** (the derived layer is forgotten, the purse persists — so an organism must keep earning). `epochs-traced` returns (answers, tr-surplus) per cycle: under **`CL_shallow`** `((2 -1)(1 0)(1 0))` — `O_chain` earns no `tr`, starves, and by epoch 2 `R_trans` can fire nothing (root answer dies, `2 → 1`); under **`CL_deep`** `((2 1)(2 1)(2 1))` — `tr` surplus +1, self-sustaining. `O_base` lives on `sm` either way; `decay` keeps molecules, drops the derived edges + event log. A final block covers the **persistence exemption**: a relation declared `(persistent R)` keeps its edge *and* its TV across `decay` while a non-persistent derived edge is dropped — the retention a control loop closes through.
- ✅ **ACS detection** (`acs_test.metta`, 79; logic `petta/acs`) — the P2 mortal-ACS certification (TECAN T3 / Alg 5.5 step 2 / MSC eq 18–19) on one chamber run. The reaction graph is keyed on the **motif** — a rule's whole reactant/product PATTERN (composite, shared vars kept; `rule-reactant`/`rule-product`), matched producer→reactant by **unification** (`motif-feeds?`), so R_trans reads as autocatalytic (its single `ReasonFor` product feeds its two-edge chain premise) and R_so/R_result as food-consumers (the `So`/`AsAResult` motifs are never produced = food). The **food-generated loop** = `{R_so, R_result, R_trans}` (all in the food-fed reaction network). **Structural closure** (§4.5 cond 1, endogenous feeds only): `R_so`/`R_result` are feed-forward cue-converters (the minting edge is FOOD, not closure), and while `R_trans` is endo-cyclic its two-`ReasonFor` premise is not **injectively** covered once the converters peel away, so the closed component is **empty**, the member set falls back to the food-fed candidate, and the set emits **no `acs-closure` fact** (a subsidized candidate, inferred as surplus-but-no-closure). Synthetic rings validate the closed branches and the **closure-kind** classifier: an all-semantic `P→Q→P` ring reads `substrate`, a control⇌semantic ring `hybrid`, a control⇌control ring `control`. **Componentwise surplus** (eq 19): `sm +1` under both clamps, `tr +1` (`CL_deep`) vs `tr −1` (`CL_shallow`) — so the **`acs-surplus` `tr` component flips** `+1`/`−1` while membership + closure stay fixed. **Condition 4 (causal influence)** is a **replay ablation** — suppressing the members in a caller-bound isolated space (`run-chamber-ablate`, fuel from `SNAP_qa`) drops the answers `2 → 0`; the negative control (suppress nothing) holds at `2`, so the assay is a real counterfactual. Emits the §2.9 verdicts as the full **A = (M_A, R_A)**: `acs-member` (R_A rules) + `acs-motif` (M_A = the cycle's motif patterns — the single ReasonFor motif AND the composite chain motif; food motifs excluded) + `acs-autocatalytic` (§4.5 cond 2) alongside `acs-closure`/`acs-surplus`/`acs-causal-influence` (cond 4, computed once)/`acs-recurrent` (there is **no `acs-promoted` summary** — the per-condition verdicts are conjoined by a consumer). Finally the **acs-scan worker** (`dispatch` → `run-as`) runs the same certification in **isolated** spaces — it **consumes** the log a prior chamber run leaves in its run space (2 answers, 3 firings), builds the graph + replays the ablation in its own graph/ablation spaces, emits the verdicts to `&self`, and a second worker under `CL_shallow` flips the `tr` surplus sign — the clamp-switch through the worker layer. Finally **recurrence** (§4.5 "sustains itself in an event log"): one chamber run = one cycle, so `acs-recurrent` is `False` (a structural candidate); a second cycle in the cycle-tagged event log (`recurrence-count`/`recurrent?`) flips it `True`, with surplus staying per-cycle (`rule-firings` scopes to the current cycle, eq-19). Then **per-rule causal coding** (SC §3): the leave-one-out `member-do-influences` measure all three V3 members load-bearing in minted reward (`R_result 6` — it makes the edge both answers need; `R_so`/`R_trans` `4` each, the chain answer), so the minimal ACS is all three. Finally **mutual redundancy** — two synthetic rules deriving the *identical* product edge, so either alone reproduces the answer but dropping both loses it: each measures do-influence `0` (a correct per-rule reading), and `minimal-acs`'s greedy sequential ablation keeps one instead of returning the empty set.
- ✅ **control-level closure** (`control_test.metta`, 35; logic `petta/acs`+`epoch`, data `experiments/expt1-causal-qa/control-*.metta`) — a causal-QA **strategy that sustains its own activation**, and the first loop here to satisfy every §4.5 condition we detect. The substrate rules are gated on an internal `Primed` state and three control rules feed a successful derivation back into it (`ReasonFor → Worked → Habit → Primed`); `R_detect`/`R_explore` sit outside, converting an arriving why-question into the first `Primed` out of a one-off `ex` exploration endowment. **Cycle 1** is the cold start (no habit, so `R_explore` ignites the strategy and spends all the `ex`); **decay** then forgets the derived layer but keeps `Habit` (the one `(persistent …)` relation); **from cycle 2** `ex` is gone and `R_explore` is silent, so `Primed` comes only from `R_prime` — the loop is the strategy's sole life support, still answering all 3 questions while earning `sm +1`/`tr +1` a cycle. **Certification**: the `endo-component` is exactly the 6-rule ring (the two food-intake rules peel out); it regenerates control motifs (`Primed`/`Worked`/`Habit`) *and* a semantic one (`ReasonFor`), so `closure-kind` is **`hybrid`**; surplus is positive componentwise; ablating the ring drops the answers to `0`; and it recurs across cycles 2–3 (cycle 1 lacks `R_prime`). Finally the **deferred death**: ablate the single closing edge `R_prime` and cycle 1 still answers `3` while cycle 2 collapses to `0` — control-level typed starvation. The three control members read `rule-do-influence 0`, which the single-cycle leave-one-out cannot see past (their products act on the *next* cycle); the deferred-death trajectory is what measures them.
- ✅ **worker isolation + the evaluator worker** (`worker_test.metta`, 16; logic `petta/chamber`+`worker`+`evaluator`) — the context-chamber worker (MSC §6.4) runs the V3 pipeline in its **own hot-pool space**, not `&self`. The runner binds the space; `run-cc` materializes the molecules into it (`copy-molecules`), restores fuel from `(snapshot-fuel …)`, and runs the chamber there. **Isolation**: after the run, `&self` has *no* derived edges and *no* event log (the molecule cue untouched); the worker's space holds the 3 `ReasonFor` edges, the 3-firing **append-only** log, and the spent purses. Grounding against the worker's space answers the question (2 ways) — the space-parameterized grounder + `clause-join` running off `&self`. `emit-summary` writes `worker-firings` + `worker-purse` to `&self`. Then an **evaluator worker** (`run-eval`, worker-kind `evaluator`) mints on that **same** derived space — the minting stage `run-cc` omits, a sequential pipeline handoff — under `CL_deep`: `O_chain` earns back the `tr` the chamber spent to 0 (+ `sm`), `O_base` earns `sm`, each grounding credited to the organism that derived it; the resulting purses are emitted to `&self` as the token delta.
- ✅ **multi-worker orchestration** (`multiworker_test.metta`, 9; logic `petta/worker`+`reducer`+`dispatch`) — the §6.4 P4 layer. Two context-chamber workers over `CH_expt1` in **separate** spaces: `W_full` unbounded (3 firings, 2 answers); `W_lean` with `(worker-budget-steps W_lean 2)` **halts after `R_so`+`R_result`** (no `R_trans` → 1 answer). **Isolation**: `W_full` spends its `tr`, `W_lean` never reaches `R_trans` so its `tr` is untouched — neither touches the other. `dispatch` routes each by `worker-kind`; the **reducer** merges the two summaries into `(reduced total-firings PG_qa 5)`, and dispatching it again stays 5 (**re-run-safe**).
- ✅ **ecan-epoch worker** (`ecan_test.metta`, 8; logic `petta/ecan`+`epoch`+`worker`) — the metabolic-closure epoch loop **re-hosted on a worker**, in an isolated space. `dispatch` routes `ecan-epoch → run-ee`, which runs the loop (mint+credit each cycle) for `worker-cycles` under `CL_shallow` in the worker's own space. Isolation: `&self` has no derived edges (the derivation lived in the worker's space).
